# Character Sprite Credits

The layered character sprites in `public/character/` (body/skin tones,
hairstyles + colors, outfits) are a curated subset of the **Liberated Pixel
Cup (LPC)** asset collection, pulled via the **Universal LPC Spritesheet
Character Generator** (https://github.com/sanderfrenken/Universal-LPC-Spritesheet-Character-Generator),
itself built from community art originally hosted on OpenGameArt.org.

These are not CC0 like the Kenney tileset — each asset below carries its
own license (typically CC-BY-SA 3.0 and/or GPL 3.0, some OGA-BY 3.0/CC0),
which is why every contributor is credited by name here per the license
terms. Reusing/redistributing this directory outside this project should
carry the same attribution.
